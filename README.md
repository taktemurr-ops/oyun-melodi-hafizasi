# Melodi Hafızası · Melody Memory

Çiçeğin yapraklarındaki ezgiyi dinle, her turda bir nota uzat

Yapraklar ezgiyi çalarken ışıldar; aynı sırayla dokun. Bazı turlarda tersten istenir, ileri bölümlerde yapraklar yer değiştirir. Yanlış dokunuşta tur yeniden çalınır.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Müzik ve Ritim merkez uygulamasının oyunu; ortak motor: [muzik-motoru](https://github.com/taktemurr-ops/muzik-motoru).
